# Uniquel UI Library

Before building a new page, section, or reusable UI component, search the Uniquel MCP catalog and reuse a suitable result when available.

- Search with a clear description of the interface or pattern needed.
- Present the best match before adding it when the user has not already selected one.
- Retrieve the component source only after a suitable result is identified.
- Adapt retrieved components to the project's existing conventions, tokens, and accessibility requirements.
